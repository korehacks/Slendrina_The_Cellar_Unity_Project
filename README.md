## 🎯 About The Project

This repository contains the Unity project source code for a first-person horror game layout. The primary goal is to recreate the chilling atmosphere, exploration mechanics, and jump-scare elements characteristic of the original *Slendrina* franchise. Players must navigate a dark, eerie cellar, hunt for hidden books/items, avoid the horrifying entity, and find a way to escape.

---

## ✨ Features

- **First-Person Controller:** Smooth movement and looking mechanics tailored for indoor horror navigation.
- **Inventory & Item Collection:** Pick up keys, books, and special items required to progress.
- **AI Behavior System:** Slendrina tracks, spawns, and attacks based on player distance and line of sight.
- **Atmospheric Lighting:** Dark, flashlight-dependent environments designed to build tension and fear.
- **Audio & Sound Effects:** Dynamic ambient sounds, terrifying jumpscare cues, and footsteps.

---

## ⚙️ Prerequisites & Requirements

To open, edit, and run this project successfully, ensure you have the following installed:

- **Unity Editor:** Recommended version **2021.3 LTS** or higher (compatible with most modern Unity 2020+ versions).
- **IDE:** Visual Studio, Visual Studio Code, or Rider configured with Unity support (C#).

## 🚀 Getting Started

Follow these steps to get the project up and running locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/korehacks/Slendrina_The_Cellar_Unity_Project.git](https://github.com/korehacks/Slendrina_The_Cellar_Unity_Project.git)

 * Open Unity Hub:
   * Click on Add project from disk.
   * Navigate to the folder where you cloned the repository and select it.
 * Open the Project:
   * Click on the project name to launch it in the Unity Editor. (Let Unity import all assets and packages).
 * Play the Game:
   * Navigate to the Assets/Scenes folder.
   * Open the main game scene.
   * Press the Play 🎬 button at the top of the Unity Editor.
⌨️ Controls
| Key / Action | Function |
|---|---|
| W, A, S, D | Move Forward, Left, Backward, Right |
| Mouse | Look around / Aim flashlight |
| E / Left Click | Interact / Pick up items |
| Shift | Run (if enabled) |
| Esc | Pause Menu |
